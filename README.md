# Excel Student Data Analysis

## Project Overview

This project analyzes student social media usage and wellbeing data using Microsoft Excel.

The analysis uses logical, conditional, error-handling, and counting functions to transform raw data into meaningful categories and summary insights.

## Objectives

- Classify students based on daily social media usage
- Identify students potentially affected academically by high usage
- Categorize students by region
- Classify mental health scores
- Calculate a sleep-to-usage ratio while handling errors
- Categorize sleep duration into bands
- Count students identified as at risk

## Excel Functions Used

- IF
- AND
- OR
- Nested IF
- IFERROR
- IFS
- COUNTIF

## Analysis Areas

- Social media usage
